# Checklist DPA (Data Processing Agreements) — AB DRIDI

**Objectif** : Signer un accord de sous-traitance (art. 28 RGPD) avec chaque prestataire traitant des données personnelles.

---

## Sous-traitants et statut DPA

- [ ] **Vercel** — Dashboard → Settings → Legal → Data Processing Addendum
  - Lien : https://vercel.com/legal/dpa
  - Action : Accepter le DPA en ligne dans le dashboard

- [ ] **Stripe** — Dashboard → Settings → Compliance → Data Processing Agreement
  - Lien : https://stripe.com/legal/dpa
  - Action : Le DPA est automatiquement accepté avec les conditions de service Stripe

- [ ] **Sentry** — Dashboard → Settings → Legal & Compliance → DPA
  - Lien : https://sentry.io/legal/dpa/
  - Action : Accepter le DPA en ligne ou télécharger et signer

- [ ] **Google** (Analytics + OAuth) — Admin console → Compte → Data Processing Terms
  - Analytics : https://privacy.google.com/businesses/processorterms/
  - Action : Accepter les Data Processing Terms dans la console admin Google Analytics

- [ ] **Neon** — Contacter legal@neon.tech
  - Lien : https://neon.tech/legal/dpa (si disponible)
  - Action : Demander le DPA par email à legal@neon.tech

- [ ] **Resend** — Contacter support@resend.com
  - Lien : https://resend.com/legal/dpa (si disponible)
  - Action : Demander le DPA par email à support@resend.com

---

## Vérifications pour chaque DPA

Avant de signer, vérifier que le DPA inclut :
- [ ] Description du traitement (finalité, données, durée)
- [ ] Obligations du sous-traitant (sécurité, confidentialité, assistance)
- [ ] Clause de sous-traitance ultérieure (notification des sub-processors)
- [ ] Clause d'audit
- [ ] Mécanisme de transfert hors UE si applicable (SCCs 2021/914 ou DPF)
- [ ] Clause de restitution/suppression des données en fin de contrat

---

**Responsable** : Bilel DRIDI
**Date objectif** : Avant le premier client payant
**Archivage** : Stocker les DPA signés dans un dossier sécurisé (Google Drive ou équivalent)
